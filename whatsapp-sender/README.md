# WhatsApp Sender (Sent API)

تطبيق إرسال حملات واتساب فوق Sent. لا يحتاج `npm install` (Node 20+ فقط).

## التشغيل
```
cp .env.example .env     # عدّل APP_PASSWORD وبيانات Sent
npm start                # http://127.0.0.1:3000  (اسم المستخدم أي شيء، كلمة المرور APP_PASSWORD)
npm test
```
الوضع الافتراضي `DRY_RUN=true`: لا يُرسل شيء، ويطبع ما كان سيُرسل. غيّره إلى `false` بعد اختبار حسابك.

## ما يفعله
- استيراد جهات اتصال من CSV (تطبيع الأرقام إلى E.164، استبعاد المكرر والخاطئ).
- **لا يُرسل إلا للموافقين**: الموافقة لا تُسجَّل إلا إذا أكدتها بنفسك عند الاستيراد، وتُفحص مرة أخرى لحظة الإرسال (إلغاء الاشتراك يتفوق).
- قوالب فقط (واتساب لا يسمح برسائل تسويقية حرة): تسجّل اسم القالب المعتمد في Sent ومتغيراته، وتربط كل متغير بحقل مثل `{name}` أو `{city}`.
- إرسال متتابع مع تأخير (`SEND_DELAY_MS`)، وحفظ الحالة على القرص، وإيقاف/استئناف. رسالة بحالة "غير معروف" بعد انهيار لا تُعاد تلقائيًا (تفاديًا للإرسال المزدوج).
- "مقبول" = Sent استلمها، وليس أنها وصلت. لا يوجد تتبع للتسليم بعد.

## غير مُتحقَّق منه
`sent.js` يفترض شكل طلب Sent (`POST /v3/messages` مع `x-api-key` و`x-sender-id` وجسم `{to, channel, template:{name, parameters}}`) من نتيجة بحث وأداة الموصّل، لأن صفحة التوثيق كانت محجوبة من بيئة البناء. لم يُجرَّب أي إرسال فعلي. جرّبه برقمك أنت أولًا.

## ليس فيه بعد
استقبال ردود STOP تلقائيًا (webhooks)، تتبع التسليم، جدولة، تعدد المستخدمين. التخزين ملف JSON واحد، يكفي لآلاف قليلة من الجهات.
